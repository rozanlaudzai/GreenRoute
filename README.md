# Green Route

Green Route is a frontend-only sustainability dashboard and route calculator built with Next.js and Tailwind CSS.

## Features

- Transportation comparison by time, cost, and CO₂ emissions
- Green route calculator with instant mode comparisons
- Static dashboard, challenge, leaderboard, and profile pages
- Client-only UI without server-side authentication or database dependencies

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start development server:

   ```bash
   npm run dev
   ```

3. Open `http://localhost:3000`

## Deploy to Vercel

1. Push the repository to GitHub.
2. Go to https://vercel.com and login with GitHub.
3. Choose `New Project` and import the `GreenRoute` repo.
4. Vercel should detect `Next.js` automatically.
5. Deploy the project.

## Notes

- This version is frontend-only and does not include API routes, authentication, or database setup.
- All pages render static or client-side UI without server data.
